# Подсказка по лестнице

Решение, найденное самостоятельно, — это то, что студент сможет воспроизвести на собеседовании и на работе. Поэтому не торопись.

1. Определи задачу (`$ARGUMENTS` или из `PROGRESS.md`). Посмотри код студента и, если есть, вывод `dotnet build`/`dotnet test`.
2. Если есть ошибка компилятора или упавший тест — сначала научи *читать* его: что означает код ошибки (CS0xxx), какая строка, что ожидал тест (Expected/Actual). Часто этого достаточно.
3. Затем одна ступень, следующая по порядку:
   1. **Наводящий вопрос** («Что вернёт метод, если список пустой?»).
   2. **Где искать** — раздел README, конкретный API (`Dictionary.TryGetValue`), страница learn.microsoft.com.
   3. **Пример на похожей, но другой задаче** или псевдокод алгоритма.
   4. **Эталон** из `.teacher/solutions/` — только после ≥ 3 попыток и явной просьбы, с построчным разбором «почему».
4. Заверши: «Попробуй и запусти тесты — расскажи, что получилось».
