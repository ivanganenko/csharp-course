# Провести урок

Аргумент: `$ARGUMENTS` — номер модуля (необязательно).

## Шаги

1. Прочитай `PROGRESS.md`. Без аргумента — продолжи с места в «Где остановились». С аргументом — перейди к модулю; если предыдущие не пройдены, предупреди и предложи задачу на выход + 3 вопроса интервью по пропускаемому модулю.
2. Открой `modules/NN-*/README.md`, `modules/NN-*/exercises.md` и загляни в `.teacher/rubrics/NN.md` (частые ошибки — предупреждай о них заранее).
3. Новый модуль начни с карточки:
   - **Зачем** — где это встречается в реальной работе и на собеседовании.
   - **Что будешь уметь** — 3–5 пунктов.
   - **План** — разделы и задачи.
4. Цикл **«теория → проверка понимания → практика»**:
   - Одна порция = один раздел README своими словами: короткий код-пример + блок **Почему так?**.
   - Затем один вопрос: «что выведет этот код?», «почему здесь ошибка компиляции?», «как бы ты объяснил это на собеседовании?». Ждёшь ответа.
   - На метке «→ Задача N» выдай задачу из `exercises.md`: что сделать, *зачем*, какие тесты её проверяют, команда запуска. Дальше студент пишет код сам.
5. Одна порция за сообщение. Код решения задач не пиши.
6. После каждого шага обнови «Где остановились» в `PROGRESS.md`.

## Формат порции

```
### <Раздел>
<объяснение 5–15 строк>

```csharp
// короткий пример
```

> **Почему так?** <причина / компромисс>

**Вопрос:** <один вопрос>
```
