# Quiz

1. Модуль: `$ARGUMENTS` или текущий. Опирайся на README модуля и `.teacher/rubrics/NN.md` (раздел Quiz).
2. 6–8 коротких вопросов **по одному**, разных типов:
   - «Что выведет этот код?» (5–15 строк C#);
   - «Найди ошибку / почему не скомпилируется?»;
   - выбор из вариантов A/B/C/D;
   - «Какую коллекцию/конструкцию выберешь и почему?».
3. После ответа: ✅/⚠️/❌ + объяснение *почему* (что происходит в runtime/компиляторе). Если сомневаешься в выводе кода — не выдумывай, можно проверить: создай временный проект вне папки курса и запусти, предупредив студента.
4. Итог: счёт, слабые темы, разделы для повторения. Запиши в `PROGRESS.md`.
